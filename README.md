# Challenges

Android-App (Flutter) für persönliche Challenges – z. B. 30 Tage um 5 Uhr aufstehen,
21 Tage ohne Zucker, 24 h nicht sprechen. Später auch gemeinsam mit Freunden.

- Arbeitsweise und Regeln: [CLAUDE.md](CLAUDE.md)
- Aktueller Stand: [STAND.md](STAND.md)
- Planung: Issues mit Label `story` und deren Sub-Issues
- Debug-APK: bei jedem Build auf `main` als Artefakt im CI-Lauf (Actions → CI → „challenges-debug-apk“)
